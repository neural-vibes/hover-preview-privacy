Hover Preview Downloader

Privacy & help · Updated 4 October 2026

Created by Aydin Gasimov and Majid Rahmanov. Find and save standalone video previews that you own or have permission to download.

What the extension accesses

On HTTP and HTTPS pages where you allow site access, the extension inspects video elements and observes media response metadata. It temporarily processes media URLs (including query parameters that may contain access tokens), media type, file size, duration, dimensions, tab and frame identifiers, detection times, and whether you hovered a video.

It does not read form entries, passwords, cookies, browsing history from the browser history API, or request authorization headers. It does not store page titles or page text. It does not record your screen.

Storage and retention

Up to 100 media candidates per tab are kept in the browser's session memory. The list is cleared when you use Clear list, on normal HTTP(S) page navigation, when the tab closes, or when the browser session ends. Sites that change pages without a full navigation may keep previous candidates; use Clear list on those sites. Extension disable, reload, update, or removal also ends this session storage.

Downloaded files and the browser's download history remain until you delete them yourself. Copy URL places the selected media URL on your system clipboard, where other software or clipboard synchronization may access it.

Network activity and sharing

No browsing data or media lists are sent to the authors. There are no analytics, advertising, remote scripts, accounts, or developer-operated servers. Data is not sold or shared for advertising.

When you choose Download, your browser requests the original file from its media host. That host receives the request and ordinary connection information, such as your IP address; the browser may send cookies under its own rules. The original URL is preserved, including its HTTP or HTTPS scheme and any signed query parameters. An actual Blob file is read locally in its owning page frame and saved using the browser's page download mechanism.

Why the permissions are needed

  • Website access: find video elements in pages and embedded frames, and identify media from separate media hosts.
  • webRequest: observe media response URLs, types, and sizes. Requests are not modified.
  • downloads: save a file only after your click and report its download status.
  • storage: retain the temporary per-tab media list while the extension worker is idle.

Your choices and limited use

Use Clear list to remove a tab's candidates, restrict site access in the browser's extension settings, disable the extension, or uninstall it. No media data is available on an author-controlled server for retrieval or deletion.

Information accessed through Chrome APIs is used solely to find and save the video files you request. This use complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

How to save a preview

  1. After installing or reloading, refresh the website.
  2. Hover a thumbnail until its video plays.
  3. Click Save preview over the video, or open the toolbar popup and choose Download. Refresh list scans the page again.
  4. Choose a destination and check the browser's Downloads page for completion.

Downloads preserve the complete source file. The extension does not trim a longer video to the duration shown in a thumbnail. Network detection can list other page videos or advertisements too.

Standalone MP4, WebM, MOV, M4V, and Ogg video files are supported. HLS/DASH playlists and separate stream segments are labeled but cannot be assembled. MediaSource blobs, DRM, image sprites, and canvas-only players are unsupported. Actual Blob files are saved using the on-video button and are not listed in the popup.

Some servers reject downloads because of expired links, login requirements, or referrer checks. Hover again to refresh a link. The extension does not bypass access controls or DRM. If the on-video button interrupts a site's hover behavior, use the toolbar popup.
